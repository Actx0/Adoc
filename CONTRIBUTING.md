## Contributing

Thanks for helping improve the Actx0 docs.

### Issues

- Search existing issues before opening a new one.
- Include the page URL or file path when reporting a docs bug.
- Review existing issues and leave feedback or reactions when helpful.

### Pull requests

- Open your pull request against `main`.
- Keep the PR focused; squash to a small number of commits when possible.
- Prefer conventional lowercase commit messages (e.g. `docs: clarify how it works`).
- Preview docs locally with `mint dev` when you change MDX, `docs.json`, or `openapi.yaml`.
- Update navigation in `docs.json` if you add or rename pages.
- Keep API reference pages in sync with `openapi.yaml` when endpoints change.
