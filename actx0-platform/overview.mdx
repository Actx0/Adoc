## Actx0 Platform

Actx0 is a hosted memory platform for AI agents. Everything is scoped to a **workspace**. Inside a workspace you create **agents**, run **sessions**, store **messages** and **memories**, manage **prompts** and **knowledge**, and issue **access keys** for SDKs and agents.

```text
Workspace
  ├── Access keys
  ├── Prompts
  ├── Knowledge documents
  └── Agents
        └── Sessions
              ├── Messages
              └── Memories
```
