# Actx0 Docs

Mintlify documentation site for [Actx0](https://actx0.com).

## Preview locally

```bash
npm i -g mint
mint dev
```

## Structure

| Path | Purpose |
| --- | --- |
| `docs.json` | Site config and navigation |
| `openapi.yaml` | REST API OpenAPI (playground + SDK samples) |
| `index.mdx` | Docs home |
| `actx0-platform/` | Platform overview, quickstart, agents, knowledge, prompts, MCP |
| `api-reference/` | API overview |
| `integrations/` | Integrations |
| `agent-plugins/` | Agent plugins |
| `release-notes/` | Platform and SDK release notes |
