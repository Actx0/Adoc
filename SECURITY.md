## Reporting a Vulnerability

Please report security issues privately. Do not open a public GitHub issue for vulnerabilities.

- Email: [hello@clivern.com](mailto:hello@clivern.com)
- Include a clear description, impact, and steps to reproduce when possible

We will acknowledge reports as soon as we can and follow up with next steps. If the report is accepted, we will work on a fix and coordinate disclosure. If it is declined, we will explain why.
