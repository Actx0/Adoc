Fetch access key metadata by ID.

## Endpoint

- **Method**: `GET`
- **URL**: `/api/v1/workspaces/{workspaceId}/keys/{keyId}`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-API-Key: <API_KEY>` or session cookie | Yes | User authentication. Access keys are not accepted for this endpoint. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Response

<CodeGroup>
```json Response
{
  "id": "key_...",
  "workspaceId": "ws_...",
  "name": "Agent runtime",
  "permissions": ["List session memories"],
  "createdAt": "2026-07-01T12:00:00Z",
  "updatedAt": "2026-07-01T12:00:00Z"
}
```
</CodeGroup>
