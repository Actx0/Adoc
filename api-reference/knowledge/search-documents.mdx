Semantic search over knowledge documents.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/documents/search`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | Yes | Search query. |
| `labels` | object | No | Optional label filters. |
| `limit` | integer | No | Max results (1–100). |

<CodeGroup>
```json Request
{
  "query": "refund policy",
  "limit": 10
}
```
</CodeGroup>

## Response

<CodeGroup>
```json Response
{
  "results": [
    {
      "documentId": "doc_...",
      "chunkId": "chunk_1",
      "score": 0.88,
      "text": "Refunds are available within 30 days."
    }
  ]
}
```
</CodeGroup>
