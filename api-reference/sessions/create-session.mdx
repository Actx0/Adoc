Create an agent session. Pass `?id=` and/or label query params to set the external reference.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents/{agentId}/sessions`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | string | No | Optional session title (max 255 characters). |

<CodeGroup>
```json Request
{
  "title": "Checkout help"
}
```
</CodeGroup>

<CodeGroup>

```json Response
{

  "workspaceId": "ws_...",
  "agentId": "agt_...",

  "status": "active",
  "labels": {},
  "createdAt": "2026-07-01T12:00:00Z",
  "updatedAt": "2026-07-01T12:00:00Z"
}
```
</CodeGroup>
