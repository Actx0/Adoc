Delete a workspace and its resources.

## Endpoint

- **Method**: `DELETE`
- **URL**: `/api/v1/workspaces/{workspaceId}`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-API-Key: <API_KEY>` or session cookie | Yes | User authentication. Access keys are not accepted for this endpoint. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

{ }
