Create a new workspace.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-API-Key: <API_KEY>` or session cookie | Yes | User authentication. Access keys are not accepted for this endpoint. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Workspace name (3–60 characters). |

<CodeGroup>
```json Request
{
  "name": "Production"
}
```
</CodeGroup>

## Response

<CodeGroup>
```json Response
{
  "id": "ws_...",
  "name": "Production",
  "handle": "production",
  "membersCount": 1,
  "role": "owner",
  "createdAt": "2026-07-01T12:00:00Z",
  "updatedAt": "2026-07-01T12:00:00Z"
}
```
</CodeGroup>
