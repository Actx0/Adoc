Create an agent in a workspace.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Agent name (1–100 characters). |
| `description` | string | Yes | Agent description (1–2000 characters). |

<CodeGroup>
```json Request
{
  "name": "Support bot",
  "description": "Handles customer support conversations"
}
```
</CodeGroup>

## Response

<CodeGroup>
```json Response
{
  "id": "agt_...",
  "workspaceId": "ws_...",
  "name": "Support bot",
  "kind": "agent",
  "handle": "support-bot",
  "description": "Handles customer support conversations",
  "status": "active",
  "createdAt": "2026-07-01T12:00:00Z",
  "updatedAt": "2026-07-01T12:00:00Z"
}
```
</CodeGroup>
