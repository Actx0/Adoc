Update an agent.

## Endpoint

- **Method**: `PUT`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents/{agentId}`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Updated name. |
| `description` | string | Yes | Updated description. |
