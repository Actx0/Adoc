Create a new version for an existing prompt.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/prompts/{promptId}/versions`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | `text` or `chat`. |
| `content` | string | Yes | Version content. |
| `config` | string | No | Optional JSON string config. |
| `commitMessage` | string | No | Commit message. |
| `meta` | string | No | Optional JSON string metadata. |
| `production` | boolean | No | Mark as production. |

<CodeGroup>
```json Request
{
  "type": "text",
  "content": "You are a concise support agent.",
  "production": true
}
```
</CodeGroup>
