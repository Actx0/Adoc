Update a prompt version.

## Endpoint

- **Method**: `PUT`
- **URL**: `/api/v1/workspaces/{workspaceId}/prompts/{promptId}/versions/{promptVersionId}`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | No | `text` or `chat`. |
| `content` | string | Yes | Updated content. |
| `config` | string | No | Optional JSON string config. |
| `commitMessage` | string | No | Commit message. |
| `meta` | string | No | Optional JSON string metadata. |
| `status` | string | No | `active` or `archived`. |
| `production` | boolean | No | Mark as production. |

<CodeGroup>
```json Request
{
  "content": "Updated prompt body",
  "production": true
}
```
</CodeGroup>
