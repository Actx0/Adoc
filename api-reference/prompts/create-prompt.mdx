Create a prompt with its first version.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/prompts`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Prompt name (1–150 characters). |
| `description` | string | No | Prompt description. |
| `type` | string | Yes | `text` or `chat`. |
| `content` | string | Yes | Prompt content. |
| `config` | string | No | Optional JSON string config. |
| `commitMessage` | string | No | Version commit message. |
| `meta` | string | No | Optional JSON string metadata. |
| `production` | boolean | No | Mark this version as production. |

<CodeGroup>
```json Request
{
  "name": "Support system",
  "type": "text",
  "content": "You are a helpful support agent.",
  "production": true
}
```
</CodeGroup>
