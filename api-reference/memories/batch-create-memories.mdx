title: "Batch Create Memories"
description: "Create up to 100 memories in one request."
---

Create up to 100 memories in one request.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents/{agentId}/sessions/{sessionId}/memories/batch`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `memories` | array | Yes | Array of memory objects (`kind`, `content`, optional `meta`). |

<CodeGroup>
```json Request
{
  "memories": [
    { "kind": "fact", "content": "User lives in Austin" },
    { "kind": "preference", "content": "Prefers dark mode" }
  ]
}
```
</CodeGroup>
