Create a session message. User messages can trigger async memory extraction.

## Endpoint

- **Method**: `POST`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents/{agentId}/sessions/{sessionId}/messages`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `role` | string | Yes | `system`, `user`, or `assistant`. |
| `content` | string | Yes | Message content. |
| `meta` | string | No | Optional JSON string metadata. |

<CodeGroup>
```json Request
{
  "role": "user",
  "content": "I prefer dark mode."
}
```
</CodeGroup>

## Response

<CodeGroup>
```json Response
{
  "id": "msg_...",
  "sessionId": "ses_...",
  "role": "user",
  "content": "I prefer dark mode.",
  "createdAt": "2026-07-01T12:00:00Z"
}
```
</CodeGroup>
