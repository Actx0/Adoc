---
title: "Batch Delete Messages"
description: "Delete up to 100 messages by ID."
---

Delete up to 100 messages by ID.

## Endpoint

- **Method**: `DELETE`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents/{agentId}/sessions/{sessionId}/messages/batch`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `ids` | string[] | Yes | Message IDs to delete. |

<CodeGroup>
```json Request
{
  "ids": ["msg_1", "msg_2"]
}
```
</CodeGroup>

## Response

<CodeGroup>
```json Response
{ }
```
</CodeGroup>
