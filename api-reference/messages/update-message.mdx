Update a session message.

## Endpoint

- **Method**: `PUT`
- **URL**: `/api/v1/workspaces/{workspaceId}/agents/{agentId}/sessions/{sessionId}/messages/{messageId}`
- **Content-Type**: `application/json`

## Required headers

| Header | Required | Description |
| --- | --- | --- |
| `X-Access-Key: <ACCESS_KEY>` | Yes* | Workspace access key. Session cookie or `X-API-Key` also work when the user has permission. |
| `Accept: application/json` | Yes | Ensures a JSON response. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `role` | string | No | `system`, `user`, or `assistant`. |
| `content` | string | Yes | Updated content. |
| `meta` | string | No | Optional JSON string metadata. |

<CodeGroup>
```json Request
{
  "role": "user",
  "content": "I prefer light mode."
}
```
</CodeGroup>
