## Actx0 REST API

Actx0 provides a REST API for integrating durable agent memory into your applications. Manage workspaces, agents, sessions, messages, memories, prompts, knowledge documents, and access keys with simple HTTP requests.

<Info>
  **Quick start:** Create a workspace access key in the Actx0 Dashboard, then make your first memory operation in minutes.
</Info>

***

## Quick Start Guide

Get started with the Actx0 API in three simple steps:

1. **[Create Memory](/api-reference/memories/create-memory)** — Store facts and preferences for a session
2. **[Search Memories](/api-reference/memories/search-memories)** — Retrieve relevant memories with semantic search
3. **[List Memories](/api-reference/memories/list-memories)** — Fetch memories for a session

## Authentication

API requests authenticate with one of:

```bash
X-Access-Key: <your-access-key>
```

```bash
X-API-Key: <your-api-key>
```

Or a browser session cookie (`_actx0_session`) for dashboard flows.

| Mode | Header / cookie | Typical use |
| --- | --- | --- |
| Access key | `X-Access-Key` | Agents, SDKs, and server integrations |
| User API key | `X-API-Key` | User-scoped automation |
| Session | `_actx0_session` | Dashboard and interactive apps |

Workspace and access-key management require a user principal (`X-API-Key` or session). Agents, sessions, messages, memories, prompts, and knowledge accept workspace access keys with matching permissions.

<Warning>
  **Keep your keys secure.** Never expose them in client-side code or public repositories. Use environment variables and server-side requests only.
</Warning>
